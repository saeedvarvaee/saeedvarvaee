# NEXUS Design System

## Purpose
A restrained visual identity for a finance-oriented professional profile.

## Palette
- Obsidian: `#080B10`
- Graphite: `#111821`
- Electric Orange: `#FF6B35`
- Amber: `#FF9F43`
- Warm White: `#F5F7FA`
- Muted Silver: `#8994A3`
- Champagne Gold: `#C8A96B`

## Principles
1. Orange is a signal, not a blanket fill.
2. Geometry should imply systems, networks and infrastructure.
3. Motion is slow and independent; no flashing or synchronized choreography.
4. Every illustration has a useful static state.
5. Typography remains readable without custom fonts.
6. The README remains useful if every image fails to load.

## Accessibility
All major SVGs expose `<title>` and `<desc>`, use high-contrast text, and include a reduced-motion media query.
